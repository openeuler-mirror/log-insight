### 功能点 7 · 智能巡检规则推荐（2026-10-13 新增）

在智能巡检详情页，对已完成（done）的巡检任务提供「智能巡检规则推荐」能力：

- **触发**：详情页点击按钮 → `POST /tasks/{id}/rule-suggestions`，返回 `run_id`（异步 + SSE 流式，与按需 LLM 报告同一范式）
- **流式输出**：`GET /tasks/{id}/rule-suggestions/events?run_id=&token=`，事件 `progress` / `suggestion_token`（增量文本）/ `suggestion`（结构化建议项）/ `done` / `error`
- **评估内容**：基于该任务解析出的日志事件与现有规则，评估当前规则覆盖度，指出未覆盖的高频错误模式，给出建议新增的规则项（名称/匹配类型/模式/级别/理由）
- **LLM 未配置降级**：走启发式评估（重解析日志、比对现有规则覆盖、关键词模式表给出未覆盖建议），不调用大模型也能产出可用建议
- **存储与交互**：
  - 结果与任务绑定（`rule_suggestions` 表），刷新 / 切换页签后仍可查看
  - **不写入巡检报告**（`reports.content` 不包含此项）
  - 评估文本与建议项**用户可编辑**
  - 每条建议支持「接纳」→ 跳转到规则管理页新增弹窗并预填该规则
- **权限**：沿用任务的可见性校验 + `task:llm` 权限点

## 硬性约束

- **日志来源**：被动上传模式（用户在目标服务器一键收集日志包后上传），不做主动采集
- **部署环境**：ARM / x86 双架构，Linux 和 Windows 均需支持，Web 端访问
- **技术栈**：Python 实现；部署方式需提供裸机（systemd / NSSM）和 Docker Compose 两套
- **UI 风格**：简约大气
- **智能能力**：规则引擎优先 + LLM 总结混合模式（LLM 未配置时降级纯规则）
